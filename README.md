# DeskMate · 桌面管家

一个常驻 Windows 桌面的整理工具：**Dock 快速启动** + **启动台** + **文件夹面板（带自建文件预览）** + **全局搜索** + **任务栏遮罩**。
纯本地 WPF 程序，不联网、不遥测、不装任何系统组件。

> 平台：Windows 10 19041+ / Windows 11，x64 · 运行时：.NET 8（发布版自带，无需另装） · 界面：WPF

## 它在解决什么

桌面堆满文件夹、常用软件散落各处、开一个文件要在资源管理器里翻三层。
Dock 和启动台管「快速到达」，文件夹面板管「这些东西都是什么、里面有什么」，全局搜索管「我忘了它在哪」。

## 功能

### Dock（屏幕底边那条）

- 应用 / 文件夹 / 分隔符 / 分组，图标可自定义，支持拖拽排序（拖动时有插入位置指示线）。
- **点已运行的应用 = 切回它的窗口**（语义和任务栏一致：在前台就最小化、不在前台就切过去），而不是再开一个实例。
- 悬停图标出**实时缩略图**（DWM 缩略图），每张缩略图标题行带一个 ×，可以直接关掉那个窗口（是 `WM_CLOSE`，程序该弹保存提示照样弹，不是杀进程）。
- 可以贴屏幕物理底边把任务栏那 48px 盖掉，也可以自动收起（移到屏幕底边唤出）。
- 全屏应用运行时自动让路（见「设计原则」第 5 条）。

### 启动台

- 扫描开始菜单 + 公共桌面 + 注册表 `App Paths`，磁贴墙 + 分类 Tab（全部 / 常用 / 办公 / 开发 / 游戏 / 学习 / 系统 / 已隐藏）。
- **拼音首字母搜索**：输 `cjgs` 能搜到「计算器」，同时支持子串、前缀、CamelCase。
- 右键可以「打开文件位置 / 固定到 Dock / 隐藏」，「已隐藏」页里能一键恢复。

### 文件夹面板（资源管理器式两栏）

左边走进文件夹，右边就地看文件内容，**两栏同时可见** —— 看了这个文件也还知道同层还有什么。

| 操作 | 结果 |
| --- | --- |
| 单击文件夹卡片 / 目录行 | 主区走进去一层（不弹资源管理器） |
| 单击文件 | 右边内容窗格就地看它的内容，左边那一页原封不动 |
| 双击文件 | 交给系统关联程序打开，同时收掉那块临时预览 |
| 按住空格 | 把内容放大成独立窗口，松手就收（QuickLook 那套手感） |
| 顶部面包屑 | 从盘符到当前层，每一段都能点 |
| 行上右键 | 打开 / 在资源管理器中显示 / **重命名** / **移到回收站** |

**自建的内容预览**（不挂系统 Shell 预览处理程序）：

| 类型 | 怎么画 |
| --- | --- |
| 文本 / 代码 | 等宽、不换行（代码折行会毁掉对齐），只读但可选中复制 |
| Markdown | 按块渲染：标题分级、列表带序号、引用、代码围栏；块内 `**粗**` / `` `码` `` 也渲染成真的粗体与等宽片段 |
| 图片 | 等比缩放居中 |
| PDF | 系统自带的 `Windows.Data.Pdf` 逐页渲成位图，**按显示宽度 × 系统缩放渲染到设备像素**（不是拉一位图），带缩放档 |
| 压缩包 | 列条目 + 大小，只列不解压 |
| Office（docx / xlsx / pptx） | 打开包读里面的 XML，**带结构**地抽：Word 的标题样式或「整段加粗 + 大字号 + 短行」→ 标题，加粗 run → 粗体片段，`w:tbl` → 等宽表格 |
| 其余 | 不装死：写清**为什么看不了**和下一步点哪 |

### 全局搜索

应用 + 受管文件夹 + 桌面文件 + 文件夹内条目，一个框里混排，同样支持拼音。零结果时给「重新扫描应用」和「在资源管理器里搜」两条退路。

### 桌面文件归类

按扩展名把桌面上的文件虚拟分成 图片 / 文档 / 压缩包 / 其他 四个 Tab，可以整片收进一个分组、可以收藏、可以拖出去上传。
**分类是虚拟的，桌面上的文件一个都不移动。**

### 任务栏遮罩（可选）

开一条窗口把任务栏左侧的图标区（开始 / 搜索 / 任务视图 / 应用按钮）盖住，填充是**壁纸在那一条上的原图** —— 不模糊、不像贴了块东西。
动态壁纸（Wallpaper Engine 等）下它靠**帧差自适应**跟着动：抓一条带子和上一帧逐字节比，变了才刷，节奏在 300ms~30s 之间自动调；壁纸不动时退到 30 秒一次，几乎不占资源。

### 其它

托盘常驻（关窗口只是隐藏）、深浅色主题、透明度可调、全局快捷键可自定义、开机自启可选。

## 设计原则（这个项目的取舍都在这里）

1. **只存路径引用，不搬你的文件。** 所有功能都不移动、不重命名、不删除用户文件；数据只写 `%APPDATA%\DeskMate\`，删掉这个目录就等于干净卸载。
   *唯一例外*：文件夹面板浏览某一层时，那一行可以重命名（只改名字、不挪位置）和移到回收站（走 shell，可还原，且必须二次确认、默认按钮是「否」）。
2. **不改系统设置。** 不写注册表（除开机自启那一条 `HKCU\...\Run`），不设置任务栏自动隐藏，不注册 Shell 扩展 / COM 预览处理程序 —— 即使"退出时会还原"也不行。
3. **预览不锁文件。** 所有读取一律 `FileShare.ReadWrite`：你的 `.c` 正开在 Keil 里、日志正在被写、PDF 正被阅读器打开时都能预览，反过来 DeskMate 也不会把这些文件锁住。PDF 因此是自己读字节再 `LoadFromStreamAsync`，而不是 `LoadFromFileAsync`（后者会一直握着句柄）。
4. **不联网、不遥测。** 没有一行网络请求。
5. **全屏时让路。** 游戏 / 视频全屏时 Dock 和遮罩自动收起。判据是「前台窗口覆盖整块显示器」，并且因为**进全屏不换前台窗口**（同一个窗口改样式和矩形），除了 WinEvent 还以 400ms 轮询重算 —— 只听前台事件的话，任务栏会藏而 Dock 不会。

## 快速开始

```bash
git clone https://github.com/<你>/DeskMate.git
cd DeskMate
dotnet run --project src/DeskMate.App        # 开发运行
```

发布一个免装 .NET 的单目录版本：

```bash
dotnet publish src/DeskMate.App -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
# 产物在 src/DeskMate.App/bin/Release/win-x64/publish/，连同 5 个 WPF 原生 dll 一起拷走
```

> 目标框架是 `net8.0-windows10.0.22621.0`（为了用系统自带的 `Windows.Data.Pdf`），所以**输出目录带平台版本号**，不是 `net8.0-windows/`。机器上不装 Windows SDK 也能编译，投影包由 SDK 从 NuGet 拉。

## 测试

```bash
dotnet test                                    # 401 个单元测试
src/DeskMate.App/bin/Debug/net8.0-windows10.0.22621.0/DeskMate.exe --smoke-test
```

`--smoke-test` 会真的把每个窗口创建、显示、操作一遍再退出，检查 XAML 资源缺失、模板绑定写错、命令取不到这类**只有真正渲染才会暴露**的问题（比如 `{Binding XxxCommand}` 拼错在编译期是完全合法的），有任何失败就以非零码退出。日志与截图存证在 `%APPDATA%\DeskMate\logs\`。

## 架构

```
DeskMate.sln
├── DeskMate.App        WPF 主程序：View / ViewModel / DI / 托盘 / 自检
├── DeskMate.Core       业务层：模型、服务、接口。不出现任何 View 类型
├── DeskMate.Interop    Win32 层：P/Invoke、图标提取、DWM 缩略图、前台切换
└── DeskMate.Tests      xUnit：单元测试 + 真开真画的窗口集成测试
```

依赖方向单向：`App → Core → Interop`。DI 用 `Microsoft.Extensions.DependencyInjection`，所有窗口和 ViewModel 都是单例（WPF 里 `Close()` 之后不能再 `Show()`，所以关窗口一律 `Hide()`，只有退出时真关）。

几处值得说的实现选择：

| 问题 | 选择 |
| --- | --- |
| 文件预览 | 自建查看器，不挂 `IPreviewHandler` —— 那是第三方 COM，会崩、会吞焦点，还得养一套"崩了就杀宿主"的机制 |
| PDF | 系统自带的 `Windows.Data.Pdf`（WinRT 投影），零外部依赖 |
| 应用图标 | `IExtractIcon` + `SHGetFileInfo`，多尺寸 `.ico` 按请求尺寸挑档；解码必须在图标线程上做完再 `Freeze`，否则跨线程读像素会炸 |
| 启动台毛玻璃 | 分层窗口不能用 DWM 背景采样 → 自己 `PrintWindow` 抓屏 → `BlurEffect` → `ImageBrush` |
| 置顶 | explorer 会不停把任务栏抬回置顶组最上面 → 轮询并沿 `GW_HWNDPREV` 直接问 Z 序。**不能**用「我自己那个像素归谁」判断：任务栏是逐像素透明的分层窗口，探测点落在透明段时 `WindowFromPoint` 会穿透返回我们自己的窗口，于是明明被压着却判成没被压着 |
| 窗口切换 | 只认可见窗口。缩回托盘的应用（微信 4 那类）在工具包层就 `hide()` 了，从外面 `ShowWindow` 只会得到一个没有内容的白框 |

## 键盘

| 键 | 作用 |
| --- | --- |
| `Ctrl` / `Shift` + 单击、`Ctrl+A` | 卡片多选（右键菜单一次作用在整批上） |
| `F2` | 重命名 |
| `Delete` | 移除引用（超过一张先确认） |
| `Esc` | 按顺序收：浮层 → 多选 → 内容窗格 → 退层 → 关面板 |
| 空格（按住） | 放大当前预览，松手关闭 |
| 滚轮 | 启动台 / 面板 / 预览列表滚动 |

## 已知限制

- **只支持主显示器**（多显示器待做）。
- UWP / 商店应用不枚举（拿不到可写路径）。
- 开机自启项在 `DeskMate.exe` 换目录后只会显示「未开启」，不会提示更新。
- 老式 Office 格式（`.doc` / `.xls` / `.ppt`）看不了，只支持 OOXML。
- 动态壁纸下任务栏遮罩最多落后 400ms（追到屏幕帧率既不划算也会吃满一条线程）。
- 「贴桌面层」模式是实验性的：依赖未公开的 `0x052C` 消息，Win11 24H2 之后桌面改成 XAML 岛可能挂接失败（失败会自动退回普通置顶，不会让 Dock 消失）。
- 「常用」页只按启动次数排序，没有时间衰减。

## 参与

想要新功能或发现 bug，先开 issue。提 PR 前请本地跑一遍：

```bash
dotnet build     # 要求 0 警告
dotnet test
DeskMate.exe --smoke-test
```

代码注释一律写「为什么」而不是「是什么」—— 这个项目里很多看似多余的判断（`FileShare.ReadWrite`、轮询 Z 序、`Hide()` 代替 `Close()`）都是踩出来的，注释要留住的是那个原因。
